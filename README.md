## Objetivo

O objetivo da atividade é criar uma API em Node.js capaz de armazenar e listar arquivos utilizando o conceito de armazenamento de objetos.

Para o armazenamento foi utilizado o MinIO executado através do Docker. A comunicação entre a API e o MinIO foi realizada utilizando a biblioteca do AWS S3.

## Tecnologias utilizadas

- Node.js
- Express
- Multer
- AWS SDK S3
- MinIO
- Docker
- Git e GitHub
